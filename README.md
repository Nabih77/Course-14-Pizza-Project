🍕 Pizza Order App (Windows Forms)

-A desktop GUI application developed in C# and Windows Forms (.NET) that simulates a pizza ordering system. This project allows users to customize their pizza, select various options, and view an instant real-time price and summary update.

📌 Features
-Pizza Size Selection: Small, Medium, Large (with dynamic price updates).
-Crust Type: Thin Crust or Thick Crust.
-Toppings Customization: Multi-select options (Extra Cheese, Mushrooms, Tomatoes, Onion, Olives, Green Peppers) with automatic price accumulation.
-Dining Option: Eat In or Take Out.
-Real-Time Order Summary: Live updates for size, toppings list, crust, dining choice, and total price.
-Order Confirmation & Lock: Shows confirmation dialog and locks controls once the order is placed.
-Reset Functionality: Easily reset the form to place a new order.

🛠️ Built With & Concepts Practiced
-Language: C#
-Framework: .NET (Windows Forms)
-IDE: Visual Studio 2022

Key Concepts:
-Event-Driven Programming (CheckedChanged, Click, Load).
-Storing numeric data inside control properties using .Tag.
-Clean modular functions (CalculateTotalPrice(), UpdateToppings(), UpdateTotalSummary()).
-Handling user dialogues using MessageBox.Show with DialogResult.
